# CLAUDE.md — mPause 컨텍스트 허브

이 폴더는 **mAuto(감독모드 매크로, `../macro/`)와 완전히 별개 프로젝트**입니다.
같은 git 레포 안에 있지만 코드·빌드·설치본을 공유하지 않습니다.

---

## 🌟 북극성

**"지정한 프로세스를 버튼 한 번으로 잠깐 멈췄다가 자동으로 되살린다"를 100% 신뢰할 수 있게 만든다.**

성공 지표:
1. 멈춘 프로세스는 **어떤 경로로 끝나든 반드시 재개된다** (창 닫기·예외·앱 종료 포함)
2. 실수로 시스템 핵심 프로세스를 멈춰 PC가 굳는 일이 없다
3. mAuto 라이센스 키로는 열리지 않는다 (제품 전용 키)

스코프 밖:
- 자동 업데이트(런처) — mAuto 와 달리 아직 없음
- 프로세스 강제 종료·메모리 조작 — 일시정지/재개만 한다

## 📦 개요

- **무엇:** 작업관리자·리소스 모니터의 '프로세스 일시 중단 / 다시 시작'을
  **버튼 한 번**으로 1회성 실행하고, 되살린 직후 화면을 인식해 마무리까지 해 주는 Windows 도구.
  대상과 시간은 `config.py` 에 고정돼 있고 UI 에는 노출하지 않는다.
- **핵심 API:** `ntdll!NtSuspendProcess` / `ntdll!NtResumeProcess` (ctypes, 리소스 모니터와 같은 호출)
- **기술 스택:** Python 3 + tkinter. 핵심 동작은 **표준 라이브러리만**으로 돌고(+ 순수 파이썬
  `ed25519_tiny`), 화면 인식·입력에만 네이티브 의존성(cv2·numpy·pywin32·windows-capture·vgamepad)을
  쓴다. 전부 `deps.py` 에서 가드하므로 없거나 실패하면 **그 기능만** 꺼지고 본체는 그대로 돈다.
- **빌드:** Nuitka `--standalone`(폴더형) + Inno Setup.

│  ├─ license_dialog.py  — 인증 화면(검증은 스레드)

  UI·오류 문구에 대상 이름이나 동작 방식 노출(`tests/test_no_leak.py` 가 막는다).

## 🧠 교훈 & 실수 노트

- **git 루트는 두 단계 위**(`GitHub/macro/`). 추적 경로는 `mpause/...`, mAuto 는 `macro/...`.
- **`PROCESSENTRY32W.th32DefaultHeapID` 는 `ULONG_PTR`** → x64 에서 8바이트(`ctypes.c_size_t`).
  크기를 틀리면 뒤 필드가 전부 밀려 exe 이름이 깨진 채로 나온다(조용히 잘못 동작).
- **`NtSuspendProcess` 는 undocumented 지만 XP 부터 안정적으로 export** 된다. 리소스 모니터가 쓰는 것과 같다.
- **관리자 권한이 없으면 다른 사용자·권한 상승된 프로세스는 못 건드린다.** `OpenProcess` 가
  `ERROR_ACCESS_DENIED(5)` 를 준다 → 사용자에게 미리 알려 주고, 오류 문구에도 안내를 붙인다.
- **`subprocess.run(text=True)` 는 이 PC 에서 cp949 로 디코딩한다.** 한국어가 섞인 출력을 읽을 때는
  `encoding="utf-8"` 을 반드시 명시(테스트에서 실제로 터졌음).
- **`node -e` 는 `process.argv[1]` 부터가 사용자 인자**다(스크립트 경로가 없어 한 칸 앞당겨짐).
